Agentic Commerce Market Intel

Thursday, October 29, 2026

Today's signals reflect the convergence of agentic commerce infrastructure: Stripe, Instinct, and Amazon are moving payments and agent orchestration into production; Walmart and Ripple are establishing governance models for agent access and stablecoin-backed transactions. H Company's enterprise computer-use deployment and Microsoft's managed agent harness indicate the infrastructure layer is solidifying. Meanwhile, Google and Meta are competing on ad placement within agent decisions, and cross-border settlement remains a constraint even as new rails emerge.

Launches

  • Stripe: Stripe Link Balance launches as pre-funded wallet for AI agents, routing fiat through stablecoins on Tempo and converting to virtual debit cards via Stripe Issuing; agentic purchases grew 38x in one month. TLDR Crypto
  • Instinct: Instinct lets users fund a wallet and set spending limits so AI agents can make independent purchases via Visa virtual card backed by stablecoin conversion. TLDR Fintech →
  • Walmart: Walmart launches Agent Profiles, Agent Gateway, and terms for agents acting on customers' behalf; sets spending limits, approval requirements, and data controls for third-party agent access. PYMNTS Agentic Commerce →
  • Google: Google expands AI Mode ads to 10 new countries (Australia, Canada, India, Kenya, Malaysia, New Zealand, Nigeria, Pakistan, Philippines, Singapore) with limited separate reporting. Google Ads & Commerce Blog →
  • Microsoft: Microsoft introduces Copilot harness in Foundry Agent Service (public preview) providing managed execution for agents reasoning, using tools, and completing complex long-running tasks. Microsoft Foundry Blog →
  • Ramp: Ramp launches Inspect, a cloud-based coding agent converting requests from Slack/GitHub/Linear into validated PRs; accounts for 74% of merged PRs, 3.4x more PRs per person. TLDR Fintech
  • Cloudflare: Cloudflare China Network now serves Turnstile challenge widgets hosted in Mainland China for faster, more reliable challenge completion without cross-border requests. Cloudflare Bots Changelog →
  • Amazon: Amazon expands Shop Direct to 250M outside-store listings (2.5x since March); Buy for Me lets shoppers authorize Amazon to complete purchases on external merchant sites. MarketMaze →
  • Amazon: Alexa for Shopping adds 100+ capabilities (gift lists, registries, refund tracking); demonstrates progression toward lifelong shopping agent remembering customer preferences and constraints. Amazon News →

Partnerships

  • Kalshi: S&P Dow Jones partners with Kalshi to offer event contracts settled against official index values; S&P will turn Kalshi probability data into new benchmarks. TLDR Fintech

Regulation
