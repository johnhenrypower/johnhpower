Agentic Commerce Market Intel

Wednesday, November 25, 2026

Agentic commerce infrastructure is crystallizing: 29% of merchants already accept AI agent purchases, though nearly half cannot identify agents in traffic, and PayPal is reframing agent transactions outside traditional dispute protections. Visa launched CLI wallet on Tempo/MPP and expanded TAP to agent wallets; Google imposed MCP requirements and usage pricing for workspace agents; and Walmart's Muse connector with Meta demonstrates the first real consumer agent-to-agent commerce flow. Payment rails, bot defense, and agent identity are converging, major platforms are building the guardrails, verification layers, and settlement infrastructure that agentic commerce requires.

Funding

  • Amazon: Acquired Decart's AI optimization technology for $7.5B; Decart Optimization Stack (DOS) makes AI run efficiently on Nvidia, Amazon, Google hardware; enables better training, inference, and cheaper models. TLDR AI →

Launches

  • Cashfree: Launches agent-enabled wallet with UPI/card/net banking funding; users set budgets and payment limits for connected agents; bill payments live, travel/food/e-commerce planned. Marcel
  • Meta: Muse personal AI agent now available in UK for adults; can complete purchases with user approval; integrates with Marks & Spencer, Currys, Ocado, Sainsbury's; uses MCP and agent approval workflows. MarketMaze →
  • Anthropic: Claude Ship agents for GitHub pull requests: Code Review flags issues, PR Steward pushes fixes, Claude Approvals checks changes against team policy. TLDR AI →
  • Privy: Added verifiable enclave attestations for wallet operations; cryptographic proof that wallet operations executed in AWS Nitro enclaves; shifts security from operator trust to external verification. TLDR Crypto →

Partnerships

  • Walmart: Walmart Agent Gateway powers Muse shopping; first consumer agent-to-agent agentic commerce connector; integrates Muse (Meta) with Sparky (Walmart); real-time inventory, cart UI, approval workflows. Retailgentic →
  • Syndigo: New partnership with Microsoft under Frontier Commerce; supports physical, digital, and AI shelf; 15,000 brands and 3,500 retailers; research shows 83% abandon digital shelf for missing info; 25% of agents buy without purchase. Retailgentic →

Also notable

  • Paysafe: Research with G2 finds 29% of merchants support AI agent purchases; 49% cannot distinguish agent from human traffic; 34% believe fraud prevention could block legitimate agent transactions. Sam from Fintech Wrap Up →
  • PayPal: PayPal excludes AI agent virtual card payments from Seller Protection; agent purchases follow card-network chargeback rules rather than PayPal's dispute process. Marcel
  • Google Cloud Platform: New Workspace API usage tiers and pricing starting April 2027; MCP requirement for AI agents accessing Workspace data; enforcement Feb 1, 2027; Scaled tier pricing for agentic use; prohibitions on scraping and certain agent activities. Google Cloud Platform
  • Stripe: Valued at above $200B in new tender offer talks; acquired AI model router OpenRouter (~$7B) and usage-based billing company Metronome; positioning for AI payment infrastructure. Marcel
  • OpenAI: OpenAI and Cisco introduced Shirudo, open-source runtime that protects running Linux systems from exploits without restart during patch rollout. TLDR AI
